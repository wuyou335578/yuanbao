# UI 图标符号数据集

UI 图标符号数据集 —— 用于几何匹配式图标识别（非深度学习训练）。

## 规模

| 项 | 数量 |
|---|---|
| 样本总数 | **32** |
| 已人工确认 | 25 |

| 类别数 | 32 |

## 目录

```
images/      归一化 64x64 二值 PNG（前景=255 白，背景=0 黑）
originals/   原始裁剪图，保留真实比例（仅真实截图样本有）
svg/         矢量 SVG，可缩放可改色（仅真实截图样本有）
labels.csv   样本清单：文件/类别/来源/是否确认
classes.txt  全部类别名
meta.json    完整元数据（含前景占比、匹配参考分）
```

## 数据格式说明

**images/ 里的图是二值 mask，不是普通图片。**

- 已经过外框裁剪 + 居中补正方形 + 缩放到 64×64
- 前景（图标本身）= 255，背景 = 0
- 这样存是因为匹配算法直接吃 mask，省掉每次重复预处理

**想看原始外观用 originals/，想改色缩放用 svg/。**

## 怎么用

```python
import icon_match

# 1. 加载本数据集作为图标库
from icon_match import save_template
import cv2
for f in os.listdir('images'):
    save_template(类别名, cv2.imread('images/'+f, 0))

# 2. 之后就能认了
icon_match.match(待识别图)
```

## 许可与来源

- `builtin_*` —— 程序化生成（PIL 绘制），无版权问题
- `capture_*` —— 来自真实 App 截图，仅供研究，**请勿商用**

## 重要提醒

**这是给「几何模板匹配」用的数据集，不是训练数据集。**

样本量只有几十个，训练模型远远不够。它的价值在于：
匹配算法只要**每个类别 1 张**就能工作，教一次永久记住。
所以几十个样本覆盖几十个类别是够用的。

`capture_*` 样本的类别是 `unknown_*`，**需要人工确认后再改 labels.csv**。
`match_guess` 字段是模板匹配的参考推测，**准确率有限，别直接当真值**。
